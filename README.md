# Harddisk LED

Gnome extension to Show harddisk activity (IO speed read/write and LED). Click to change modes

https://extensions.gnome.org/extension/988/harddisk-led/

## Preferences

Open the preferences dialog (`gnome-extensions prefs harddiskled@bijidroid.gmail.com`) to

- **Mode** – select the currently active display mode
- **Default mode** – mode applied when the extension is loaded; *None* keeps the last used mode
